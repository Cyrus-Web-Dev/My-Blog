- **VS Code**: editor dengan ekosistem ekstensi besar.
- **Git**: pengendali versi yang wajib dikuasai.
- **Browser DevTools**: tab Network, Performance, dan Application menjawab banyak pertanyaan frontend tanpa alat tambahan.
- **Bruno** atau **Insomnia**: klien API untuk mencoba endpoint. Bruno menyimpan koleksi sebagai file di repo sehingga mudah di-versi.
- **curl**: cara tercepat mencoba request dari terminal dan menyalinnya ke dokumentasi.
- **jq**: merapikan dan menyaring JSON di terminal.
- **DBeaver Community**: klien database untuk banyak jenis database.
- **Excalidraw**: menggambar diagram arsitektur seperti sketsa di papan tulis.
- **Mermaid**: menulis diagram dari teks, enak untuk README.

Satu tips: pilih sedikit alat dan kuasai betul, daripada punya banyak yang setengah dipakai. Dan untuk layanan hosting dengan paket gratis, cek selalu batas terbarunya sebelum bergantung padanya.
